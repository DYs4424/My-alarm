# My-alarm
My Alarm - Aplikasi Alarm Tugas Kuliah PWA dengan icon jam pink bunga

Aplikasi alarm pengingat tugas kuliah berbasis PWA (Progressive Web App) yang bisa di-install jadi APK Android.

**Live Demo:**
- Netlify: https://alarm-buat-tugas.netlify.app
- APK: Download di Releases

### ✨ Fitur
- Alarm tugas kuliah
- Icon custom jam pink bunga
- Bisa di-install di HP Android (PWA to APK)
- Offline ready

### 🛠️ Dibuat dengan
- HTML, CSS, JavaScript
- PWA (manifest.json + Service Worker)
- PWABuilder untuk generate APK

### 📱 Cara Install
1. Buka link Netlify di HP
2. Klik Install / Add to Home Screen
3. Atau install file `My Alarm.apk`
